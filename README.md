# GameVault - Video Game Collection Tracker

GameVault is a web application designed to help users organize and explore a collection of video games. Users will be able to view information about each game and eventually add, edit, and manage games through the application.

The application will manage a collection of video game items organized by different categories and genres. Each game item is expected to include the following fields:

- `id`
- `title`
- `category`
- `description`
- `platform`
- `genre`
- `imageUrl`

## Planned Data Model

Each video game in my collection will have the following fields:

* **id** – A unique identifier for each video game.
* **title** – The name of the video game.
* **category** – The type or genre of the game, such as RPG or Action RPG.
* **description** – A brief description of the game.
* **platform** – The platform where the game can be played.
* **developer** – The company or developer that created the game.
* **image(s)** – A link or path to an image representing the game.
